# Rota Segura Assessoria — Site Institucional Multi-Página

Site institucional demonstrativo estruturado em múltiplos arquivos HTML, com estilos e scripts compartilhados e separados para facilitar manutenção e organização.

> **Observação:** Marca, textos institucionais e dados de contato são fictícios, criados exclusivamente para fins de portfólio e demonstração técnica.

## Estrutura de Arquivos
- `index.html` — Página inicial com proposta principal, frentes de atuação, método em etapas e chamada para contato.
- `sobre.html` — Apresentação da empresa, abordagem, princípios e perfil de clientes atendidos.
- `servicos.html` — Detalhamento dos serviços e formatos de contratação.
- `contato.html` — Formulário de contato, canais/horário de atendimento e perguntas frequentes (FAQ).
- `css/styles.css` — Estilos globais, variáveis de cor, layout responsivo e componentes.
- `js/script.js` — Destaque do link ativo da página atual, menu mobile, acordeão do FAQ, validação do formulário e botão flutuante de retorno ao topo.

## Tecnologias Utilizadas
- **HTML5** (múltiplas páginas semânticas)
- **CSS3** (Grid, Flexbox, variáveis CSS e responsividade)
- **JavaScript** (interações de navegação, FAQ, formulário e rolagem)
